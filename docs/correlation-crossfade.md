# 相关度自适应交叉淡化：推导、实现与实测

结论：对等功率、局部平稳且已经对齐的两路音频，把原有互补的 sin²/cos² 权重除以其预测混合功率的平方根，可以消除由相关度不足造成的**期望功率**凹陷；这一恒等式不能保证任意语音的每个短时 RMS 都恒定。建议 Mimic 先替换全带交叉淡化并记录真实电平、相关度和限幅次数，再考虑分带版本。

参考代码：[correlation_crossfade.py](correlation_crossfade.py)。代码仅依赖 NumPy，注释为英文，不修改引擎。本文推导独立于外部实现，所有性能数字是本机实测，所有声学效果推论均需实际语音 A/B 验证。

## 1. 从功率约束到闭式增益

用 x、y 表示两路波形，用 a、b 表示增益，避免把波形和增益记成同一个符号。先假设去除 DC 后二者具有相同功率 P：

\[
E[x^2]=E[y^2]=P,\qquad E[xy]=\rho P,\quad -1\le\rho\le1.
\]

输出 z=ax+by，其功率为

\[
E[z^2]=a^2P+b^2P+2ab\rho P.
\]

所以目标约束是

\[
\boxed{a^2+b^2+2\rho ab=1.}
\]

现有淡化取 s∈[0,1]、θ=πs/2、u=cos²θ、v=sin²θ，u+v=1。未经修正的功率比

\[
D=u^2+v^2+2\rho uv=1-2(1-\rho)uv.
\]

中点 u=v=1/2，D=(1+ρ)/2；ρ=0、0.5、0.8 对应 −3.010、−1.249、−0.458 dB。块边界重复出现这一包络凹陷，就可能形成块同步的电平调制。

保留原有增益比 b/a=v/u，只增加共同的归一化因子 g。由 g²D=1 得

\[
g=\frac1{\sqrt{u^2+v^2+2\rho uv}},\qquad
\boxed{a=\frac{u}{\sqrt D},\quad b=\frac{v}{\sqrt D}}.
\]

代回即可得到功率约束。端点严格为 (a,b)=(1,0)、(0,1)。ρ=1 时 D=1，退化为原有振幅互补淡化；ρ=0 时 a²+b²=1。θ 的导数在两端导致 u、v 的斜率为零，因此端点增益变化平滑。

### 1.1 单调性证明

令 q=v，q 随 s 单调从 0 到 1，则

\[
D(q)=1-2(1-\rho)q+2(1-\rho)q^2,\qquad b(q)=qD(q)^{-1/2}.
\]

求导：

\[
\frac{db}{dq}=\frac{D-\frac12qD'}{D^{3/2}}
=\frac{1-(1-\rho)q}{D^{3/2}}.
\]

当 ρ≥0，分子在 [0,1] 上非负；因此 b 单调从 0 到 1，a 也对称地单调下降。这覆盖题设 ρ=0.3–0.95。

也可以预先指定单调 b(s)，解关于 a 的二次方程：

\[
\boxed{a=-\rho b+\sqrt{1-(1-\rho^2)b^2}},\quad\rho\ge0.
\]

例如 b=sin²(πs/2)；该公式与上面的“保持原有增益比”参数化具有相同功率约束，但淡化轨迹不同。另一个等价的椭圆弧参数化是 φ=arccosρ，a=sin[(1−s)φ]/sinφ、b=sin(sφ)/sinφ，ρ→1 时取连续极限 (1−s,s)。后者在 ρ=0 时就是 cos/sin equal-power crossfade。

### 1.2 负相关的限制及处理

**ρ<0 时，连续增益、严格功率约束、端点 (1,0)→(0,1)、b 全程单调且不超 1，这四个条件不能同时成立。** 从二次根可见，由起点连续出发必须先走正根；当 b=1 时正根给 a=−2ρ>0，而终点 a=0 位于负根。两根相接要求 b=1/√(1−ρ²)>1，因此不能在 b≤1 的范围内换根。

上面的归一化参数化对 −1<ρ<0 仍保持功率和端点，但 b 会先超过 1 再回到 1。其最大值为 1/√(1−ρ²)。当 ρ→−1，两路接近相消，需要很大的增益；ρ=−1、x=−y 时，任何连续淡化都要经过零输出，无法保非零功率。

工程处理优先顺序：

1. 检查 SOLA 错配、极性错误及浊音半周期错位；在允许的搜索范围内重新对齐，记录出现次数。
2. 若相关度只是轻微为负，可允许轻微增益超 1，使用真实 ρ 做归一化，同时把共同 g 限制到例如 2（+6.02 dB）。限幅激活后不再宣称严格保功率。代码采用这一明确策略。
3. 若产品要求两路增益绝不超 1，可把估计相关度夹到非负区间并接受残留凹陷；ρ<0 时这种处理无法保真实功率。不要对波形随块随意翻转极性，切换本身会引入边界问题。
4. 低能量/无声区冻结估计或退回振幅互补，并设功率地板；不要把近零能量中的随机相关度用于大幅增益。

即使 ρ≥0，保 RMS 也不等于保 peak；需要沿用引擎已有 headroom，并记录削波，不能把硬削波当作淡化算法的一部分。

## 2. 相关度与输入功率的估计

### 2.1 全段估计及误差

50 ms 的两段重叠已在内存中，最便宜的是整段去均值后计算

\[
\hat\rho=\frac{\sum_n(x_n-\bar x)(y_n-\bar y)}
{\sqrt{\sum_n(x_n-\bar x)^2\sum_n(y_n-\bar y)^2+\epsilon}}.
\]

这只需几个长度 2400 的 dot product。`correlation()` 对静音返回 0，输入输出都需要既有 DC 去除；否则 Pearson ρ 不描述实际 mean-square power。

全段 ρ 对元音稳态较合适；跨越起音、清浊切换或音高跃迁时，50 ms 平稳假设可能不成立。不要每个采样独立估计相关度：极短窗口会跟随音频载波，使增益变成新的调制源。实时实现可使用 10–20 ms 的平滑统计并限制增益变化率；平滑会降低对突变的跟踪能力。

若真实相关度为 ρ，使用估计值 ρ̂，那么等功率模型下

\[
\frac{E[z^2]}P=1+2ab(\rho-\hat\rho).
\]

在对称中点 2ab=1/(1+ρ̂)，因此相对功率误差是 (ρ−ρ̂)/(1+ρ̂)。例如 ρ̂=0.5、估计偏差 ±0.1，偏差约为 ±0.29 dB；统计估计和局部非平稳性会直接限制改善幅度。

### 2.2 不等功率版本

若 Px≠Py，仅使用 ρ 无法让两个原始端点同时具有同一恒定功率，除非改变至少一个端点电平。应定义平滑的端点功率目标

\[
P_*(s)=uP_x+vP_y,\qquad C=E[xy],
\]

\[
Q=u^2P_x+v^2P_y+2uvC,\quad
\boxed{z=\sqrt{P_*/Q}\,(ux+vy).}
\]

这样 g 两端都是 1，不会突然改变端点电平。`covariance_crossfade()` 实现该版本，统计使用原始二阶矩，因而包含 DC。若希望物理意义上的统一恒功率，必须在更长时间尺度上先做有 attack/release 的两路 level match，并明确会改变端点；不要在每个 50 ms 窗口独立强制归一化整路音量。

## 3. 六带 STFT 版本与状态连续性

结论：分带估计可以区分“低频谐波相关、高频噪声不相关”，但增加估计方差及处理状态，不能由 STFT 系数的功率恒等式直接推断最终时域短时 RMS 恒定。

参考参数为 48 kHz、512 点 FFT（10.67 ms）、hop=128（2.67 ms）、六带 0–250–700–1600–3500–7500–24000 Hz。window 使用 periodic sqrt-Hann，分析与合成各乘一次，以逐点除以重叠 window² 之和实现 normalized overlap-add。

对第 m 帧、频带 k，计算

\[
P_{x,k}=\langle|X_{m,f}|^2\rangle_{f\in k},\quad
P_{y,k}=\langle|Y_{m,f}|^2\rangle_{f\in k},\quad
C_k=\Re\langle X_{m,f}Y^*_{m,f}\rangle_{f\in k}.
\]

ρk=Ck/√(Px,k Py,k)。必须使用 cross-spectrum 的实部，不能使用 |cross-spectrum| 或 magnitude-squared coherence 代替：后二者会把反相也判断为高度相关，从而漏掉相消。对于 DC/Nyquist 边带的更精确绝对 PSD 估计可以加入 one-sided Parseval 权重；这里各带仅用于同带增益比，所有项采用一致统计。

对三组二阶矩同时做 EMA，代码的更新系数为 0.35；这样协方差矩阵保持半正定，避免分别平滑 ρ、Px、Py 产生不一致。按不等功率公式计算每带的正实数共同 g，再沿频率平滑插值。输出频谱为

\[
Z_{m,f}=g_{m,f}\,[u_mX_{m,f}+v_mY_{m,f}].
\]

正实数增益不自行重置任何相位；两路混合后的相位仍可能因真实抵消而变化，因此这不是 harmonic phase alignment。频率插值和时间平滑减少 zipper noise，不能消除全部谱修改副作用。

真实接入必须满足以下连续性条件：

- 使用绝对采样位置定义 fade progress，保留分析 ring、EMA 与 synthesis OLA tail；跨块不能重新初始化 FFT 起点和 OLA。参考函数一次分析完整 50 ms，展示计算逻辑，属于 offline reference，不能逐块直接调用后硬拼接。
- 使用淡化区两侧真实流的上下文。代码为了独立数组可运行而用 reflect padding；生产中用真实上下文替换。围绕淡化区的全部相交 STFT 帧都要纳入渲染，区外权重延伸为 (1,0) 或 (0,1)，并让 fade 在窗口支撑内平滑收敛。独立数组函数不保证首尾单个采样恰等于原始 x、y，不能把数组首尾再次硬切到外部流。
- centered STFT 需要 256 个采样（5.33 ms）的右上下文；如果现有重叠缓存已包含这些采样，不额外增加系统 lookahead，否则需计入延迟。完整频带窗口长 10.67 ms，状态和输出调度必须按这一支撑长度安排。
- 任何 time-frequency gain 修改都可能使 STFT 不完全 consistent；normalized OLA 保证同路输入 identity reconstruction，不保证修改频谱后的逐频带能量严格保留。需测真实音频、接缝差分、RMS 与听感。

## 4. 与 phase-vocoder crossfade 的对比及组合

| 情况 | 相关度归一化淡化 | Phase-vocoder 类淡化 |
|---|---|---|
| 已对齐、谐波相位接近 | ρ→1，接近原振幅互补，改动小；噪声分量的能量凹陷可补偿 | 可能有收益，但额外相位处理可能改变瞬态和谐波结构 |
| 同一 f0 但存在残余相位差 | 按真实协方差补偿统计能量，不能纠正周期内部抵消与波形形状 | 合理的相位轨迹可改善谐波连续性，需要维护瞬时频率/谐波关系 |
| 相位近随机、ρ≈0 | 退化为 equal-power，保期望能量；两路纹理仍可能叠加 | 相位重构可能提高相干度，也可能产生 smear/phasiness；具体效果依赖实现 |
| 起音、清浊切换、强非平稳 | 单个 ρ 无法描述局部变化，仍可能出现电平起伏 | 频域时间扩展和新合成分量也不保证短时恒功率 |

可组合方案优先为“对齐/相位连续处理 → 对最终两路估计协方差 → 一次归一化淡化”。若相位处理已改变波形，必须重新估计其相关度，不可沿用处理前的 ρ。

题设 Applio 公式还有第三个合成分量 c，其功率不能假设与 x、y 独立。若输出写为 w1 x+w2 y+w3 c，应估计完整 3×3 协方差矩阵 Σ，再用共同 g=√(P*/(wᵀΣw))。六个独立二阶矩都不可省略，否则遗漏互相相关的交叉项，可能进一步放大波动。该共同增益仍只保统计功率，且需要限幅和平滑。建议先测试纯两路版本，判断当前 2–4 dB 波动中有多少来自谱/相位重建，再决定是否保留第三路；数学上不能从其幅度表达式直接宣称恒功率。

## 5. 可复现测试与结果

在仓库根目录执行：

```powershell
& '.\.venv\Scripts\python.exe' -I -B '.\docs\correlation_crossfade.py' --test --benchmark
```

本机为 Python 3.12.10、NumPy 2.5.4。采样率 48 kHz，N=2400，10 ms rectangular RMS 窗、1 ms hop，只统计完整窗口。固定随机种子 20261027。

构造单位功率公共源 s=sin(2π200t)+0.4sin(2π600t)+0.2sin(2π1000t)，再归一化。两路噪声在 5 ms 周期内随机生成、带限到 ≥6 kHz，并对 s 和彼此作 Gram–Schmidt 正交及功率归一化。形成

\[
x=0.15\,[\sqrt\rho s+\sqrt{1-\rho}n_1],\qquad
y=0.15\,[\sqrt\rho s+\sqrt{1-\rho}n_2].
\]

5 ms 周期重复十次，得到确切可控的全段 ρ；这是稳态、周期带限噪声的验证 fixture。它有意控制局部能量，不代表任意语音或独立逐样本白噪声。

| 目标/实测 ρ | 原 sin²/cos² 短时 RMS 峰峰 dB | 自适应后峰峰 dB |
|---:|---:|---:|
| 0.30 / 0.300000 | 1.6179 | **0.0748** |
| 0.50 / 0.500000 | 1.0776 | **0.0464** |
| 0.80 / 0.800000 | 0.3933 | **0.0187** |
| 0.95 / 0.950000 | 0.0947 | **0.0060** |

四组均通过 <0.3 dB 断言。表中原淡化的数值不同于理论瞬时中点凹陷，是因为 10 ms RMS 窗会平均增益轨迹，且不覆盖淡化外部的完整端点窗口。

另有不重复的 Gaussian 噪声压力测试，仍控制全段相关度，但局部能量自然起伏：

| ρ | 自适应后短时 RMS 峰峰 dB |
|---:|---:|
| 0.30 | 0.7892 |
| 0.50 | 0.8412 |
| 0.80 | 0.6353 |
| 0.95 | 0.3432 |

这不是隐藏的失败：它说明“全段相关度已知”不足以保证每个 10 ms 窗都 <0.3 dB。真实说话本身有动态，追求任意窗口绝对恒 RMS 会把交叉淡化变成 AGC，可能损坏语音包络。若严格要求这个指标，必须说明输入平稳性、RMS 窗、端点电平和可接受的 AGC 行为。

测试还覆盖：ρ=0/0.3/0.5/0.8/0.95/1 的功率恒等式误差 <1e−12、端点、b 单调性；ρ=−0.5 的增益超调及恒等式；ρ=−1 时限幅后无 NaN/Inf；同路 x=y 的全带 identity 与 STFT normalized OLA 最大误差 <1e−12；分带异路结果为有限值。

## 6. 计算量与实现建议

| 实现，每次 50 ms / 2400 点 | 复杂度 | 本机 median | 本机 p95 |
|---|---|---:|---:|
| 全带相关度 + 增益 + 混合 | O(N) | 0.0409 ms | 0.0559 ms |
| 不等功率二阶矩 + 混合 | O(N) | 0.0471 ms | 0.0817 ms |
| 六带 STFT，512 FFT / 128 hop | O((N/H)F log F) | 0.4093 ms | 0.7048 ms |

全带重复 2000 次、STFT 重复 200 次，另有 10 次预热；性能测试计入 Python 函数内部数组分配，未计入音频 IO、推理和线程调度。512 点、50 ms 数组参考实现约 20 个 STFT frame，三组 FFT/IFFT 批量执行。时间来自同一次运行，系统负载变化会影响分位数；它支持该机器上 <1 ms 的计算目标，不是实时截止时间保证。

Rust 接入时在处理线程预分配 2400 点增益与工作区，fade 曲线可缓存，避免在音频 callback 运行 Python 或做 FFT 分配。第一阶段用全带版本；保留输出 peak、10/20 ms RMS、真实/估计相关度、g 限幅命中率及块同步调制频谱。若低频/高频相关度明显不同再启用六带。所有比较使用相同输入、模型噪声、绝对相位和对齐结果，避免把上游重复渲染变化误归因于淡化算法。
